# 0.0.0-phase5.29 behavior

Phase 5.29 recognizes exactly one DKMS-built module represented as `.ko`,
`.ko.xz`, `.ko.gz`, or `.ko.zst` before applying the existing `modinfo`
identity checks. It preserves Phase 5.28 canonical kernel-header resolution
and does not enable output or widen route support.
