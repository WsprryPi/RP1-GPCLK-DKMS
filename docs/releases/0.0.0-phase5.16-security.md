# 0.0.0-phase5.16 security notes

This development successor remains fail-closed and output-disabled. It adds no
live eligibility, GPIO output, clock enablement, DMA submission, transmitter,
SDR, or RF permission.

Executable Gate D plans bind immutable source bytes separately from installed
tool bytes. Copied tools must have equal source and installed digests;
target-built helpers must carry a separately sealed installed digest. Missing,
malformed, changed, symlinked, or incorrectly classified tools fail preflight.
The older single-digest plan schema is historical-only.

Concrete attempt documents and execution evidence are excluded from the module
archive and installation; they remain separately reviewed test inputs, not an
operator or product interface. The device remains root-owned mode `0600`; no
privilege or access model changes in this successor.
