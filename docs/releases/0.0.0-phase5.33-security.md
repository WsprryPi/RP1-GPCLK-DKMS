# 0.0.0-phase5.33 security notes

Qualification tool replacement is limited to a closed absolute-path graph with
exact predecessor and successor hashes, ledgered atomic rename, authenticated
backup, and fail-closed recovery. Unknown bytes, symlinks, duplicate paths,
ambiguous ledger states, and changed backups or successors are rejected.

This remains an unpublished, output-disabled development candidate.
