# 0.0.0-phase5.2 behavioral release notes

This packaging candidate preserves UAPI ABI 1 and the Phase 4 bounded execution
implementation, but deliberately demotes the new module identity to
live-ineligible. It adds a deterministic release-unit generator, independent validator,
machine-readable installation inventory, deny-by-default populated
compatibility manifest, reproducible GPIO4/GPIO20 DTBO artifacts, provenance,
checksums, read-only diagnostics, and operator signing guidance.

The release version is `0.0.0-phase5.2` and the expected publication tag is
`v0.0.0-phase5.2`. It has no positive compatibility entries: changing the
module version and archive identity invalidates Phase 4's exact candidate
identity. Live eligibility is therefore false until later exact lifecycle and
qualification gates add reviewed evidence.

No installation, signing-policy enforcement, key enrollment, target lifecycle,
GPIO, transmission, calibrated measurement, RF, or WsprryPi integration claim
is made by this release-unit slice.
