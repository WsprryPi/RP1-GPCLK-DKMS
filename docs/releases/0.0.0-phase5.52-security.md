# 0.0.0-phase5.52 security

The initial downgrade preflight uses only sealed document identities. It
requires the prior boot identity to equal the row's top-level kernel identity,
requires the normal and prior kernels to differ, and rejects missing,
malformed, or inconsistent inputs. The same selected identity governs both
the running-kernel and signing-policy checks.

No authorization, output enablement, GPIO, clock, DMA, Si5351, SDR,
transmission, or RF capability is added by this candidate.
