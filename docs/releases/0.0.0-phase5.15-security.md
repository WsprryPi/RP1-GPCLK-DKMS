# 0.0.0-phase5.15 security notes

This development successor remains fail-closed and output-disabled. It adds no
live eligibility, GPIO output, clock enablement, DMA submission, transmitter,
SDR, or RF permission. The separate Gate D busy-state injector rejects
`LIVE_ELIGIBLE`, requests no submission capability, submits no work, accepts
only GPIO4 or GPIO20, uses a bounded hold, and releases only its own lease.

The injector is installed as a root-only qualification helper and remains
non-submitting. Concrete attempt documents and execution evidence are excluded
from the module archive and installation; they remain separately reviewed test
inputs, not an operator or product interface. The device remains root-owned
mode `0600`; no privilege or access model changes in this successor.
