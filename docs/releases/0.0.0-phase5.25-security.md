# 0.0.0-phase5.25 security notes

The schema-2 pre-root envelope authenticates the complete release-sidecar
graph and requires exact `SHA256SUMS` membership and hashes. Missing, swapped,
stale, substituted, symlinked, duplicate, and misplaced release inputs fail
before administrator invocation.

Recovery invokes administrator recovery only when an exact real transaction
state exists and the journal proves invocation began. Pre-invocation and
pre-state failures require an unchanged empty runtime baseline; ambiguous or
foreign state fails closed. Cleanup remains limited to authenticated
pre-root-owned paths and output remains disabled.
