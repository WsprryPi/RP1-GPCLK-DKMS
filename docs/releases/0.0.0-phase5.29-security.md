# 0.0.0-phase5.29 security

Built-module discovery is confined to the exact package, version, kernel, and
architecture DKMS output directory. Absence, ambiguity, symlinks,
non-regular files, and unknown module compression suffixes fail closed. The
administrator does not decompress, rename, or copy the discovered module, and
retains version, vermagic, signer, and key-ID verification.
