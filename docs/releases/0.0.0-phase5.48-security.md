# 0.0.0-phase5.48 security

Phase 5.48 removes the unsafe assumption that Gate D services are inactive at
attempt start. The canonical snapshot is the authority for the exact
pre-attempt state of all four controlled services. Coverage, state/action
compatibility, per-attempt isolation, and cross-document consistency fail
closed.

All work remains output-disabled. This freeze does not authorize module
installation, load, bind, overlay changes, service mutation, GPIO output,
clock enablement, DMA submission, Si5351 or SDR operation, antenna connection,
transmission, or RF activity.
