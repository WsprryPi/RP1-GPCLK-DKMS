# 0.0.0-phase5.27 behavior

Phase 5.27 is an unpublished successor candidate. It preserves Phase 5.26
behavior except that the administrator accepts the stock kernel's final
`/lib/modules/KERNEL/build` symlink when its strictly resolved, protected
directory is below `/usr/src`. It does not enable output or widen route support.
