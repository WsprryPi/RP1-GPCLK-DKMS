# Release 1.1.2 behavior

Release 1.1.2 is an unreleased GPIO4 live-qualification-enablement candidate.
It preserves ABI v2, both inactive route overlays, and the stable
`rp1-gpclk-route-manager-v1` application contract. It does not add an output
operation to the route manager.

The 1.1.1 package cannot enter the planned Slice 6 carrier attempt because its
exact-route compatibility policy rejects both routes even when the immutable
`live_output=1` load-time gate is requested. Version 1.1.2 replaces only the
GPIO4 placeholder with an exact qualification-candidate entry for Raspberry Pi
5 Model B, BCM2712, `aarch64`, kernel `6.18.34+rpt-rpi-2712`, module 1.1.2,
route 1, the canonical GPIO4 overlay, RP1 GPCLK0, and the already validated
resource topology. GPIO20 remains unavailable and cannot inherit GPIO4
evidence.

This entry permits the exact GPIO4 build to enter one separately authorized,
externally planned qualification attempt. The module reports that state as
`Experimental`, never `Qualified`. It does not establish completed carrier,
lifecycle, timing, frequency, spectral, transmitter, SDR, keyed-mode, product,
or RF qualification.

`live_output` remains disabled by default and read-only after load. Explicitly
requesting it is insufficient unless the exact route, kernel, architecture,
model, module, device-tree, clock, DMA, provider, and resource identities all
pass. ABI-v2 finite TONE remains kernel-bounded; the intended later request of
1,000,000,000 ns is inside the unchanged 1,000,000 through 120,000,000,000 ns
range.

Package installation remains route-neutral and output-inactive. It installs
the module source, inactive overlays, stable route manager, schema,
documentation, and disabled socket units without loading the module, selecting
a route, enabling output, opening the endpoint, acquiring resources, or
rebooting.

The predecessor output-inhibited evidence establishes only route-manager and
cleanup behavior for its exact package. It is an explicit prerequisite for
entering the GPIO4 candidate workflow; it is not live qualification for the
changed 1.1.2 bytes. Exact 1.1.2 installation, target identity, physical
confirmation, WsprryPi policy, and the reviewed bounded plan remain required.
