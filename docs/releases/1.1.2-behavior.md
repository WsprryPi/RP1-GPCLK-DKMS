# 1.1.2 archive-layout behavior contract

This version-specific document is consumed by retained archive layouts and
package-contract regression tests. It is not the current development release
or a qualification record. Current versions and installation transitions are
specified by the [development identity contract](../contracts/development-identity.md).
Generation of these older release sets is disabled on the development baseline.

The archive must carry its declared UAPI, source, overlay and compatibility
identities without substituting current bytes under old hashes. GPIO4 is route 1
and GPIO20 is route 2; route evidence is independent. `/dev/rp1-gpclk` is the
canonical endpoint. Validate exact member inventories, hashes, package version
and installed-module transforms; version ordering alone establishes none of them.

Package installation leaves both overlays inactive. It does not select a route,
load or bind the module, enable output, or authorize transmission. Separate
module, package and runtime identities must be validated before use. A successful
archive check is not installation, waveform, timing, cleanup, product or RF
qualification. Current resource and lifetime requirements are in the
[module contract](../contracts/rp1-gpclk-dkms-module-contract.md).
