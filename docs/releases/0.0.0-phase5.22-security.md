# 0.0.0-phase5.22 security notes

The outer executor uses a standard-library trust preamble to authenticate the
instance, qualification-root marker, target plan, root validator, and complete
transitive Gate D Python import graph. It reads and hashes every module before
executing any of them, then compiles the verified bytes directly without a
verify-then-reopen window. Missing, extra, swapped, stale, symlinked, writable,
or substituted modules fail closed before mutation.
