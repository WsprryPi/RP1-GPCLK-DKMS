# 0.0.0-phase5.30 security

Installed-module discovery is confined to the running kernel's real
`updates/dkms` directory through the bounded canonical `/lib` topology.
Absence, ambiguity, symlinks, non-regular files, and unknown compression
suffixes fail closed. The administrator does not decompress, rename, or copy
the module and retains version, vermagic, signer, and key-ID verification.
