# 0.0.0-phase5.53 security

The boot-operation constructor accepts only a sealed prior-kernel downgrade
row with consistent normal/prior kernel identities, an absolute non-root
staging namespace, and complete digest-bound boot inputs. Test-owned firmware
filenames are deterministic; backup and state remain attempt-owned. The
existing boot selector independently validates the generated document and all
referenced bytes before boot mutation.

No authorization, output enablement, GPIO, clock, DMA, Si5351, SDR,
transmission, or RF capability is added by this candidate.
