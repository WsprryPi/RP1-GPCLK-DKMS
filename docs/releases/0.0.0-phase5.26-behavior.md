# 0.0.0-phase5.26 behavior notes

Phase 5.26 corrects packaged operator documentation to describe the actual
transmitter topology. The Si5351 is a separate I2C-controlled RF output path
and is not wired to GPIO4 or GPIO20; those pins are reserved for the RP1 GPCLK
DKMS module.

The existing `si5351Disconnected` control field means that the disabled and
unkeyed Si5351 RF output is isolated from the antenna or test-output path. It
does not assert a physical connection between the Si5351 and either GPIO pin.
Module runtime behavior, UAPI, overlays, schemas, and output-disabled lifecycle
semantics are unchanged.
