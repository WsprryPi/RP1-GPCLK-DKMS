# 0.0.0-phase5.50 behavior

Phase 5.50 adds execution-instance schema 6. It binds schema-2 attempt
generation through `attemptSchemaVersion=2` and permits deterministic control
construction before authorization only when `approved`,
`targetExecutionApproved`, and `executionReady` remain consistently false.

Schemas 1 through 5 retain their prior authorization requirements. The module
runtime, UAPI, routes, lifecycle operations, and output-disabled policy are
unchanged.

This candidate is not lifecycle-ready until its exact deterministic archive,
representative build, successor controls, and explicit authorization are
independently established.
