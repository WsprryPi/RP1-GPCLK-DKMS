# RP1-GPCLK-DKMS 1.1.0 planned security notes

The candidate fails closed without exact route, lease, generation,
compatibility, and live-eligibility identities. Continuous TONE has no hidden
duration but remains kernel-owned and is forcibly stopped on lease loss. Finite
TONE has an independently enforced 120-second maximum. Prior GPIO4 evidence is
not transferred; GPIO20 remains unavailable.
