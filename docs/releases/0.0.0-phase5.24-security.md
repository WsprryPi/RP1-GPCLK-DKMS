# 0.0.0-phase5.24 security notes

The target-plan schema no longer permits an object where the permanent
validator requires an ordered operation list. Exact-plan regression tests bind
the published schema and validator to the same production-shaped document and
reject duplicate, missing, reordered, substituted, and unsafe envelopes.

All pre-root and root-bound output-disabled safeguards from Phase 5.23 remain
unchanged.
