# 0.0.0-phase5.31 security

Removal command failures are not ignored or classified from error prose. The
candidate issues an exact DKMS status query and requires a successful empty
result. Any present state, other-kernel state after whole-version removal,
ambiguous output, or failed query remains fatal. Forced removal, unrelated
package inspection, and weakening of owned-path identity checks are prohibited.
