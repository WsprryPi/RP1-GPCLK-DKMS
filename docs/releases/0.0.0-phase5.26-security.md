# 0.0.0-phase5.26 security notes

Phase 5.26 preserves the Phase 5.25 fail-closed and output-disabled safety
boundary while correcting misleading packaged topology text. During release
lifecycle qualification, the separate Si5351 path remains disabled, unkeyed,
and isolated from the antenna or test-output path. No antenna may be connected
to either transmitter path, and SDRplay remains unused.

The correction does not authorize GPIO output, active pinctrl, GPCLK or clock
enablement, DMA submission, transmitter keying, Si5351 or SDR operation, RF,
forced removal, fallback, or unreviewed persistent system changes.
