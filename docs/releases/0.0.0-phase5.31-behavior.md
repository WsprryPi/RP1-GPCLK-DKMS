# 0.0.0-phase5.31 behavior

Phase 5.31 makes the permanent Gate D removal primitive idempotent for a
verified already-absent exact DKMS scope. A failed uninstall or removal is
accepted only after an independent bounded status query proves the required
package/version/kernel or whole-version state absent. It preserves Phase 5.30
module-representation handling and does not enable output or widen routes.
