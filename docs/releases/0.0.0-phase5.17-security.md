# 0.0.0-phase5.17 security notes

Qualification installation is not a general development-install bypass. It
accepts only a real, non-symlink identity document with an exact closed schema,
matching release, source commit, and archive digest, `publishable: false`,
`tagPresent: false`, `outputDisabled: true`, `liveOutput: false`, and the fixed
Gate D representative-qualification purpose.

Publishable artifacts are rejected in qualification mode, unpublished
artifacts remain rejected in normal mode, and all archive and checksum
validation occurs before system mutation. No live-output, GPIO, clock, DMA,
transmitter, SDR, antenna, or RF authority is added.
