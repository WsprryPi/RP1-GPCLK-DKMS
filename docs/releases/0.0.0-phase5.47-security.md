# 0.0.0-phase5.47 security

Phase 5.47 permits only the exact kernel-provided device-tree alias and exact
canonical target. It rejects a changed or missing alias, unsafe resource
names, symlinked canonical components or resources, non-directory resources,
and descendant symlinks. The general controlled-path resolver remains strict.

The candidate is not lifecycle-ready until new exact controls are generated,
independently validated, and separately authorized. Output stays disabled.
