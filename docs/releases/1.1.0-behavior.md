# RP1-GPCLK-DKMS 1.1.0 planned behavior

Version 1.1.0 adds ABI v2 explicit continuous and finite TONE support. Existing
WSPR and keyed-event semantics and all ABI v1 identities remain unchanged.
This is a hardware-free candidate: neither GPIO4 nor GPIO20 is live-eligible.
See `docs/contracts/uapi-v2.md` for normative lifecycle details.
