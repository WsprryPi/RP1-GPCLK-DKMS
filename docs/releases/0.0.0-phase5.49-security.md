# 0.0.0-phase5.49 security

Phase 5.49 closes the terminal staging-residue defect and rejects
permission-denied protected-path probes instead of misclassifying them as
absence. Cleanup remains confined to the exact attempt-owned staging path and
rejects symlinks before recursive removal.

This freeze does not authorize installation, module load, binding, overlay or
service changes, GPIO output, clock enablement, DMA, Si5351 or SDR operation,
antenna connection, transmission, or RF activity.
