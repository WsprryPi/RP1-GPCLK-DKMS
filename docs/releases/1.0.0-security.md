# RP1-GPCLK-DKMS 1.0.0 security notes

The module remains fail-closed for unknown hardware, route, resource, kernel,
or compatibility identity. Only GPIO4 and GPIO20 are allowlisted through
separate inactive overlays. The UAPI does not expose arbitrary physical
addresses, DMA channels, register writes, or unrestricted programs.

The conventional product package excludes qualification tooling, target
evidence, credentials, private keys, and historical control bundles. Module
installation alone does not authorize output or create technical isolation
from other privileged software. The stock clock provider's private lease
cannot be recreated by this out-of-tree consumer.

The signed source tag is `v1.0.0`. Release security and provenance claims remain
bounded to the published artifacts and the qualification stated in the release
notes; they do not transfer to rebuilt or modified artifacts automatically.
