# 0.0.0-phase5.18 security notes

Bootstrap accepts literal reviewed argv only, records an atomic journal,
requires exact candidate, qualification-identity, administrator, and retained
tool hashes, and proves empty inactive runtime state before and after. Missing,
changed, symlinked, interrupted, or residual state fails closed. No GPIO,
clock, DMA, SDR, transmission, or RF authority is added.
