# 1.0.1 archive-layout security contract

This required archive-layout input supports package-contract regression tests;
it supplies no recorded-run evidence or current release authorization. See the
[development identity contract](../contracts/development-identity.md) for the
current development and publication boundary.

Release inputs must preserve SPDX notices, source provenance and license texts.
Do not distribute private signing keys, weaken signing policy, overwrite foreign
files or remove unattributable state. Member inventories and checksums identify
bytes; they are not signatures, operator authorization or qualification.

Unknown route, artifact, resource, ownership and cleanup identities fail closed.
GPIO4 and GPIO20 require independent compatibility decisions; no fallback route
or raw userspace MMIO path exists. A failed or incomplete operation retains its
owned recovery state. See [signing](../operator/signing.md) and
[lifecycle](../operator/lifecycle.md) for current operating requirements.
