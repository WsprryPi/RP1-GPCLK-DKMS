# Release 1.1.1 security boundary

ABI v2 ioctl numbers, sizes, limits, capabilities, route values, and endpoint
remain byte-for-byte unchanged from the 1.1.0 UAPI freeze. The build identity
changes to 1.1.1 because qualification tooling and artifact bytes changed.

The candidate remains deny-by-default. Its target plan authorizes nothing and
requires separate authorization for installation, each boot edit, and each
reboot. Output-disabled inspection rejects missing or duplicate live nodes,
wrong route or pin, absent binding, noncanonical endpoint publication, and any
enabled `live_output` state. It performs no endpoint acquisition, GPIO output,
clock or DMA work, carrier generation, SDR capture, transmission, or RF work.
