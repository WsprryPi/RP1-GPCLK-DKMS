# 0.0.0-phase5.17 behavior notes

This development successor preserves the module, UAPI, and output-disabled
lifecycle behavior of Phase 5.16. It adds a separate qualification-install
entry condition for bootstrapping the permanent Gate D executor from an exact
sealed unpublished candidate.

Normal installation continues to require a publishable release. Qualification
installation requires an explicit flag and a separate immutable identity whose
release, source commit, archive hash, unpublished state, purpose, and
output-disabled invariants match the release metadata.

No Phase 5.17 representative build or target lifecycle row has executed. This
successor is untagged, unpublished, and not consumable by WSPR-Transmitter or
WsprryPi.
