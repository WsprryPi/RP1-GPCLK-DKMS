# 0.0.0-phase5.2 security notes

This release candidate defaults live output off, exposes no `/dev/mem` or raw
MMIO interface, accepts only the GPIO4 and GPIO20 route overlays, and expects a
root-owned `0600` device node. Unknown release, UAPI, kernel, DT, overlay,
signer, compatibility, cleanup, or enrollment identity remains unavailable.

The stock clock provider cannot exclude all direct-MMIO or uncooperative
software. A clean diagnostic result is not proof that interference is absent.
Private signing keys are administrator-owned, are not release artifacts, and
must never be placed in the source or release directories.

No security vulnerability is represented as fixed by this packaging-only
release unit. Target lifecycle and enforced-signature testing remain separate.
