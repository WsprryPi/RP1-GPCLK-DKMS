# 0.0.0-phase5.52 behavior

Phase 5.52 is a non-publishable development candidate that corrects the Gate D
prior-kernel downgrade row's initial preflight ordering. Initial preflight now
requires the sealed normal kernel before the attempt-owned boot selection;
the existing post-reboot step continues to require the sealed prior kernel.

Other matrix rows retain their top-level kernel identity. This candidate does
not change the UAPI, route policy, output-disabled safety contract, lifecycle
recipe, or deferred environmental rows. It does not qualify GPIO output,
transmission, RF behavior, timing, or hardware coexistence.
