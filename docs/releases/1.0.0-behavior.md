# RP1-GPCLK-DKMS 1.0.0 behavior

Version `1.0.0` is the selected initial semantic release candidate. It provides
a conventional Debian DKMS package containing the bounded RP1 GPCLK module
source, canonical UAPI, and inactive GPIO4 and GPIO20 overlays. Installation
does not select an overlay, load the module, edit boot configuration, or enable
output.

Phase 5.54 development-package evidence demonstrated inactive installation,
separate GPIO4 and GPIO20 output-disabled administrative lifecycles, complete
removal, and reinstall on the representative Raspberry Pi 5. The final
`1.0.0-1` artifact must receive its own exact-identity verification before
release review.

No live-output, timing, transmission, RF, arbitrary-kernel, or application
qualification is claimed.
