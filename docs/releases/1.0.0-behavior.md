# RP1-GPCLK-DKMS 1.0.0 behavior

Version `1.0.0` is the initial published release. It provides
a conventional Debian DKMS package containing the bounded RP1 GPCLK module
source, canonical UAPI, and inactive GPIO4 and GPIO20 overlays. Installation
does not select an overlay, load the module, edit boot configuration, or enable
output.

The published `1.0.0-1` package passed inactive installation, separate GPIO4
and GPIO20 output-disabled administrative lifecycles, complete removal, and
reinstall on the recorded Raspberry Pi 5 stock-kernel configuration. The
downloaded public artifacts were checked
against the published release after publication.

No live-output, timing, transmission, RF, arbitrary-kernel, or application
qualification is claimed.
