# 0.0.0-phase5.23 security notes

The pre-root path requires an explicit envelope SHA-256, verifies the staged
executor and pre-root module bytes, rejects an existing or symlinked root, and
uses a durable external journal. It creates a UID-bound mode-0700 root, copies
only hash-bound control files, verifies the installed tooling and empty
output-disabled baseline, and rejects replay after the root exists.
