# 0.0.0-phase5.49 behavior

Phase 5.49 adds opt-in Gate D attempt schema 2. Successful schema-2 attempts
remove their exact owned staging tree after service restoration and before
residue audit and evidence sealing. The residue audit accepts only an
authoritative `ENOENT` result as proof of absence.

Schema-1 controls remain reproducible and unchanged. The module runtime, UAPI,
routes, and output-disabled policy are unchanged.

This candidate is not lifecycle-ready until its exact deterministic archive,
representative build, successor controls, and explicit authorization are
independently established.
