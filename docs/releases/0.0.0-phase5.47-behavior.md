# 0.0.0-phase5.47 behavior

Phase 5.47 accepts the exact Raspberry Pi kernel device-tree alias
`/proc/device-tree` to `/sys/firmware/devicetree/base` while continuing to
reject symlinks in every other controlled path. The fixed `rp1-gpclk`
resource is resolved beneath the direct canonical root. Module runtime
behavior is unchanged from Phase 5.46.

Gate D controls and any target lifecycle execution remain pending.
