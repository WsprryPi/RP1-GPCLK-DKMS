# 0.0.0-phase5.50 security

Phase 5.50 closes the frozen-tool authentication gap that prevented an exact
archive from validating schema-2 attempts before authorization. The attempt
schema version is explicit and immutable in schema 6, inconsistent approval
states fail closed, and prior schema behavior is preserved.

This freeze does not authorize installation, module load, binding, overlay or
service changes, GPIO output, clock enablement, DMA, Si5351 or SDR operation,
antenna connection, transmission, or RF activity.
