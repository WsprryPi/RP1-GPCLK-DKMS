# 0.0.0-phase5.30 behavior

Phase 5.30 recognizes exactly one installed DKMS module represented as `.ko`,
`.ko.xz`, `.ko.gz`, or `.ko.zst` before applying the existing `modinfo`
identity checks. It preserves Phase 5.29 built-module resolution and does not
enable output or widen route support.
